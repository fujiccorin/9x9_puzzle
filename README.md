# 九九パズル（9x9 Puzzle）

小学生向けのブラウザゲーム。九九の答えを手がかりに、ピースを9×9の盤面に敷き詰めるジグソーパズルです。

## ゲーム仕様

### ゲームボード
- 9×9（81マス）の九九の答えが書かれた盤面

### ピース
- 正方形が2～5個つながった形
- ピースには**答えの数字のみ**が書かれている
- **ピースは回転しない**（縦長なら「縦の段」、横長なら「横の段」として配置）

### ゲームプレイ
1. 右側に置かれたピースをドラッグして盤面に配置
2. 数字を手がかりに「このピースが何の段か」を推測する
3. すべてのピースが盤面を過不足なく埋めたらクリア
4. タイマーで速さを競う

### プレイヤー
- 小学2年生以上を想定
- 全学年共通難易度（同じ土俵で異学年対戦可能）
- スコアはスクリーンショットで他者と比較（外部へのデータ流出なし）
