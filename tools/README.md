# Pattern Builder - 九九パズル開発ツール

## 概要
九九パズル用の「完成形パターン」を GUI で簡単に作成できる開発者専用ツール。

## 実装ロードマップ

### Phase 2-1
- [ ] index.html (HTMLのみ実装)

### Phase 2-2

### Phase 2-3

### Phase 2-4
- [ ] export.js (JSON エクスポート)

## 使い方（準備中）

```bash
cd tools
python -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```
